01 · 结论与边界

两条来源、一个按钮、三种导出

表格有两条来源：GFM 表格与 CSV 围栏；下载都落到同一个 CsvDownloadButton。整条回答的 .md 导出是第二个入口。服务端生成文件、Excel 导出都不做。

01 / OWNS

本格拥有的

lib/csv.ts（读写两端）、lib/download.ts（Blob 下载 + 文件名清洗）、表格样式与「下载 CSV」、CSV 围栏成表、回答行「导出 .md」、标题透传。

02 / NOT OWNS

不归本格的

Markdown 渲染主体、引用、流式与 Mermaid（4.4，带徽章）；Mermaid 的「导出 JPEG」也在 4.4。服务端 artifact、Excel / 其他格式导出仍在 Deferred。

03 / HONESTY

不猜数据

CSV 解析不了（引号不闭合、中途冒引号、只有一列、超过 300 行）就退回代码块；列数不齐原样显示，不补空也不截断。

02 · 全局地图

下载只有一条路：Blob → objectURL → 一枚锚点

  1. 表格来源 A：GFM 表格 → react-markdown 渲染出 thead/tbody → 从 hast 节点取纯文本当 CSV。
  2. 表格来源 B：CSV 围栏 → parseCsv() → 自己拼 table。
  3. 导出：csvText() 加 BOM/转义/注入防护 → downloadText() → downloadBlob()。
  4. .md：直接把模型原文交给 downloadText()，不在前端重新拼。

32function parseCsv(Text: string): string[][] | null {
33 const Source = Text.startsWith('\uFEFF') ? Text.slice(1) : Text
34 const Rows: string[][] = []
35 let Row: string[] = []
36 let Cell = ''
37 let Quoted = false
38
39 for (let i = 0; i < Source.length; i += 1) {
40 const Char = Source[i]!
41 if (Quoted) {
42 if (Char === '"') {
43 if (Source[i + 1] === '"') {
44 Cell += '"'
45 i += 1
46 } else {
47 Quoted = false
48 }
49 continue
50 }
51 Cell += Char
52 continue
53 }
54 if (Char === '"') {
55 /* 引号只能出现在单元格开头；中途冒出引号说明这不是能安全解析的 CSV */
56 if (Cell !== '') return null
57 Quoted = true
58 continue
59 }
60 if (Char === ',') {
61 Row.push(Cell)
62 Cell = ''
63 continue
64 }
65 if (Char === '\r') continue
66 if (Char === '\n') {
67 Row.push(Cell)
68 Rows.push(Row)
69 Row = []
70 Cell = ''
71 continue
72 }
73 Cell += Char
74 }
75 if (Quoted) return null
76 if (Cell !== '' || Row.length > 0) {
77 Row.push(Cell)
78 Rows.push(Row)
79 }
80
81 const Filled = Rows.filter((Cells) => !(Cells.length === 1 && Cells[0]!.trim() === ''))
82 if (Filled.length < 2 || Filled.length > CSV_MAX_ROWS) return null
83 if ((Filled[0]?.length ?? 0) < 2) return null
84 return Filled
85}

16/** 已经把内容做成 Blob 的（JPEG 这类二进制）走这一支：不再经过字符串 */
17function downloadBlob(Filename: string, Payload: Blob): void {
18 const Url = URL.createObjectURL(Payload)
19 const Anchor = document.createElement('a')
20 Anchor.href = Url
21 Anchor.download = Filename
22 Anchor.click()
23 window.setTimeout(() => URL.revokeObjectURL(Url), 0)

26function safeFileName(Source: string, Fallback: string): string {
27 const Cleaned = [...Source]
28 .map((Char) => (/[/\\:*?"<>|]/.test(Char) || Char.codePointAt(0)! < 0x20 ? ' ' : Char))
29 .join('')
30 .replace(/\s+/g, '-')
31 .replace(/-+/g, '-')
32 .replace(/^-+|-+$/g, '')
33 const Sliced = [...Cleaned].slice(0, MAX_NAME).join('')
34 return Sliced === '' ? Fallback : Sliced
35}

06 · 取舍与踩坑

四条“看起来对、其实会坑人”的选择

A / PARSER

手写 RFC 4180

papaparse 能省 40 行，但这里只需要“能不能安全当表看”这一档；手写规则可测、可拒收，不引入一条新的依赖。

B / REFUSE

宁可代码块

错位的表比代码块更难发现；所以解析失败一律回退，列不齐也照实显示，不替用户“修”。

C / WIDTH

表格按内容宽

w-full 会让 9 列表格把「产品经理」压成竖排；w-max + 横向滚才对。长备注封在 24rem 内换行。

D / GUARDS

被仓库守卫抓的三下

hex 兜底色 → 改 white；role=status 不能包在条件渲染里 → 常驻槽；禁用态 opacity-50 → 全站口径 40。
