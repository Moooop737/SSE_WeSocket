01 · 结论与边界

这一格交付什么，不交付什么

代码库不是知识库语料：不进 resources、不写 chunks/embeddings、不进检索，也没有资源回收站与 content_hash 去重。它复用 DB/ObjectStore/config/日志这些基础设施，领域语义全部独立。

01 / DOMAIN

独立 codebases 域

新表、新能力盒、新 /codebases 路由；状态只有四态 uploading / processing / ready / failed，硬删直接清行。

02 / SAFETY

不解压、不执行

complete 时只读 ZIP 中央目录：拒绝 ..、绝对路径、反斜杠、重名、符号链接、设备文件、加密条目；不把任何条目写到文件系统。

03 / READ

manifest + 按需读

扁平清单持久化到 manifest jsonb；树由前端合成；预览用 S3 range reader 只读目标条目，文本一律 text/plain + nosniff。

不属于 5.4：解压到工作区、sandbox 执行、Git clone、增量更新/版本对比、AST 依赖图与代码 RAG、ZIP 批量下载、资源回收站、content_hash 去重。

02 · 全局地图

ZIP 留在对象存储，DB 只存清单

上传只建行 + 签 PUT；complete 才校验；读侧不再解析整包，只按 manifest 的 entry_index 回到 ZIP 读单个条目。

上传与校验

  • createuploading + presignPut
  • PUT浏览器直传 ZIP
  • completestat → 临时 ZIP → yauzl
  • 结果ready / failed

持久化形状

  • manifestpath / entry_index / is_dir
  • 统计file_count / declared_bytes
  • 树前端由 path 合成
  • 正文不进 DB

读与删

  • tree读 manifest
  • fileS3 range + yauzl
  • original302 presigned GET
  • delete对象 → 行，硬删

核心约束：不解压条目、不执行仓库内容。临时落盘的只有上传的 ZIP 本身（供 yauzl 读中央目录），finally 必删；预览直接从 S3 按 range 读，不落盘。

03 · 小白词典

读代码前先对齐六个词

中央目录
ZIP 尾部的条目索引，记录每个文件的名字、偏移、压缩/解压大小。只读它就能拿到清单，不用解压正文。
entry_index
条目在 ZIP 里的原始序号；预览时用它回到 ZIP 找同一条目，是 manifest 与对象之间的键。
manifest
扁平条目数组，持久化在 codebases.manifest jsonb；树是展示层产物，不重新解析 ZIP。
range GET
只向 S3 请求对象的某一段字节。yauzl 读中央目录、读单个条目都靠它，不必下载整包。
硬删
没有 deleted_at：先幂等删 MinIO 原 ZIP，再删行；不做回收站。
nosniff
X-Content-Type-Options: nosniff，阻止浏览器把文本猜成 HTML/SVG 去执行；预览永远按纯文本显示。

08 · 取舍与踩坑

为什么是这些形状

DECISION 01

代码库与知识库分离

代码是文件管理，不是语料。独立表/路由/UI 避免污染六状态、去重、回收站，也不把代码强行塞进 embed/检索。

DECISION 02

无沙箱就不解压

只读中央目录 + 按需读条目，不把仓库内容落到文件系统、不执行脚本。以后确需工作树/AST/执行时再上 sandbox（P3 后另立）。

DECISION 03

manifest 持久化

每次请求重新解析 ZIP 会把中央目录读放大成上千次 S3 请求。清单一次写好、树直接读 DB；正文仍以 ZIP 为准，预览前核对漂移。

DECISION 04

预览永远纯文本

ZIP 里的 HTML/SVG 不可信。统一 text/plain + nosniff + <pre>，浏览器没有机会把它当页面执行。

  • 高 entryIndex 预览曾经超时：yauzl 每读一条中央目录记录就 read(46B)；没有块缓存时 1493 条目要发上千次 Range GET。1MB 块缓存修掉，条目正文仍单次 range。
  • 反斜杠路径必须靠 strictFileNames：yauzl 默认不拒；打开 strict 后才按规范拒绝，错误文本再归类成 E_ZIP_PATH。
  • 清单会与 ZIP 漂移：预览按 entry_index 回查后还要核对文件名/加密/可解码，否则可能读到别的条目。
  • route 文件别导出页面组件：TanStack autoCodeSplitting 会把组件搬走，导出值变 undefined；route 只留薄壳。
