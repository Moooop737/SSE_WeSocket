HOW TO READ

怎么用这些页

  1. 先看图：每页顶部有一张内联图；先看边界与失败分支，再看一句话结论。
  2. 点注解：右边卡片点一下，左边代码对应行高亮；代码来自当前工作区。
  3. 看徽章：后续 story 的补丁用 2.5、DI、3.2 标出，不是本页交付。
  4. 行号会漂：代码改动后要在同一次改动里重建对应页。
READING ORDER

推荐顺序

1.1 → 1.4 打地基；2.1 → 2.6 看问答链；3.1 → 3.4 看 trace。每页独立，也可以按问题直接跳。

生成记录：每页的 config、memlog、validation 在 .runs/<epic-story>/；页面本身不进 app/web 构建。
