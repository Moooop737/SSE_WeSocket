01

七把刀SCAMPER Method

同一套 Widget / 头像 / 侧栏 / 入库面板，被七把刀各割一遍。Eliminate 与 Reverse 各留下一条最可能直接落地的。

21 idea · 7 knives
S

Substitute

替换
  1. 把 Widget 的四个按钮（左移/右移/换宽/移出）换成一套「面板即插口」隐喻——每张卡有一个拖拽把手，但保留按钮作为键盘等价路径
  2. 把头像的两档 CSS 径向渐变整个换成一只 WebGL shader 圆，用同一套 @theme token 取色，品牌色不再例外
  3. 把入库页右侧「这条管线在做什么」那块介绍，换成一条会动的管线进度带（抓取→解析→切块→嵌入→写库），介绍由动画自己讲
C

Combine

合并
  1. 把侧栏自定义与概览面板自定义合并成同一个「 customize 」动词与同一套存档 hook，界面只在两处入口
  2. 头像 shader 与概览空态的 ShaderBackdrop 共用一个调色板发生器，用户配好的头像色可以一键广播成全站强调色
  3. 把入库面板的 URL/正文二段切换与「最近入库」合并成一张时间线卡，输入在上方、刚进来的在下方同一视野
A

Adapt

借用
  1. 借音乐 DAW 的轨道布局做概览面板——每张卡是一条可折叠轨，宽度=该指标的重要度
  2. 借 macOS 通知中心的「分组+聚合」做侧栏——同类导航聚合成一枚可展开的胶囊
  3. 借游戏 HUD 的血条设计做 StatusBar：把状态分布做成一根会呼吸的管线带
M

Modify

改变
  1. Widget 提供三种尺寸（1/2 列 + 一个「全宽高卡」）而不是两档，并把 resize 做成可撤销
  2. 头像 shader 参数做成 6 个可组合旋钮（效果类型/配色/速度/尺度/噪点/边框），任何组合都存本机
  3. 入库表单在提交中把已完成步骤点亮（抓取完成→解析完成…），而不是只有一个 spinner
P

Put to other use

另作他用
  1. pulse 柔光这层不只给忙状态，也用来标「刚刚变过的那张卡」（5 秒内）
  2. Find 过滤框除了筛导航，兼作全站命令面板入口（mod+K 二次按下进命令模式）
E

Eliminate

删除
  1. 删掉入库页所有介绍性段落，只留一个 placeholder 与一个「下一步会发生什么」的 inline 计时
  2. 删掉概览页编辑态的「加回」独立条，改成卡片之间插入一张虚线空位（少一块 UI，位置语义更直白）
  3. 删掉卡片 exit 动画里的 scale，只留 opacity——scale 与 layout 投影同元素是布局挤压 bug 的温床
R

Reverse

反转
  1. 不是「卡片从面板移出」，而是「面板挑卡」：默认只显示 3 张，其余在抽屉里，用户是往里加而不是往外删
  2. 不是用户去找数据，而是让最紧急的那张卡自己爬上来（有 failed 时失败清单自动置顶并发光）
  3. 侧栏不排「页面」，排「意图」（我要找答案 / 我要喂库 / 我要看健不健康），页面变成意图下的子项
closer

SCAMPER 收尾：Eliminate 那条（去掉 exit 动画里的 scale）与 Reverse 那条（面板挑卡）是本轮最可能直接落地的两条。

跨域采蜜Cross-Pollination · ER / 机场 / 唱片柜 / 相机取景器 / 图书馆

左边是外来的行业，右边是偷回来的东西。桥越粗，说明这条花蜜最后真的进了本轮清单。

17 idea · 16 桥
急诊室分诊台ER triage
入库队列照 triage 做——每条待入库带一个「预计还需 N 秒」与一条色带，越久等越往左移，护士（用户）一眼看到谁在恶化

棋盘 / 桌面游戏board game
Widget 换位用「棋子抬起-落下」两帧（阴影变大→变小），比现在的 transform 补间更能表达「换了个格子」
电梯面板lift panel
侧栏自定义用「按楼层」隐喻——用户点亮的入口留在面板上，没亮的灰掉但不删
调音台mixing desk
把「视效强度」做成一个总推子（0 静默 / 1 克制 / 2 尽情），一键决定全站动画与 shader 的密度，减动效不再是二进制
电视购物反面样本
抽卡/开箱机制用在入库成功上（chunk 数与命中质量是一次开箱），提高重复入库的愉悦——需谨慎，容易变噪音

地图 Applock & follow

自动驾驶 HUDradar

03

推到十一Crank the Dial to 11 · 把视效这一维推到荒谬极值

黑方块是极值本身（全部推到 11），橙刻痕是这一条能偷回来的位置。极值不负责落地，负责告诉你方向。

13 idea
extreme value · 视效这一维的荒谬极值
01234567891011
极值整站背景是一块持续流动的 shader 海洋，卡片是浮在水面的纸
可偷的减法只让「空态与 404」这两块面有活着的底，有内容的卡静默
极值每张卡都有自己心跳，频率=它背后数据的更新频率（探针 30s 一跳、入库 3s 一跳）
偷下来就是「呼吸节奏携带信息」而不是装饰
极值鼠标经过时全站纸纹被推开一道涟漪（Fluid / LiquidMetal）
降级代价高，但可降级成只在概览的空态那一条带上做一次
极值所有数字变化都走一次全息拆解-重组（Heatmap + HalftoneDots）
偷成最小的KPI 数字换值时做一次 halftone 溶解再聚拢
极值主题切换不是换色，是一段 1.2s 的日蚀（GodRays 从边缘吃掉亮色）
可降级成 400ms 的径向擦除，成本一个 shader
极值入库这一步可视化成一颗种子长成卡片（Metaballs 合并），完成后卡从光团里凝结出来
留在 11这一条没有递减，它只是把「写入」这件事说得有物理感
极值侧栏每条导航的图标在 hover 时各自播放 200ms 的专属微动效
偷成：只有当前页那一项有常驻极慢动效，其余静止（一处动、全场静）
极值滚动时全站有一层跟随视差的纸纹颗粒（DotGrid 密度随 scrollY 变化）
偷成：只在 hero 与空态做一次极轻视差
极值每个 shader 都能被用户调（30 个效果 × 8 参数）
偷成：头像只暴露 3 个维度但正交组合（效果 × 色族 × 速度），组合数已经够多
极值光标本身是一枚透镜（LensDistortion），底下内容被放大折射
偷成：只在画廊页玩，不进主流程
极值WebGL 预算从 2 提到「按屏幕面积配额」
原则大面给一个全屏 shader，小面一律 CSS，配额本身是设计约束的来源
极值把「减动效」做成审美而不是无障碍默认：静默档 = 全站零动画、零 shader，只剩纸纹与 hairline
升格作为第三档主题
core stealable principle

Dial-to-11 的核心可偷原则：动要携带信息（节奏=更新频率）、一处动则全场静、静默档当一档审美而非降级。

04

把它当材质来问Sensory Exploration · 手感 / 声音 / 温度 / 湿度 / 重量 / 味道

每张卡下面那块是这条感觉的实物演示：hover 会压下去、会显影、会抬起落下；声音是一次短闪，常亮只属于正在进行的事。

8 idea · 6 senses
touch · 触感

卡片是「纸」不是「玻璃」

按下不做 scale 收缩（那是玻璃），而是纸被压下去一点（阴影变浅 + 1px 下沉），与既有 paper 语义一致

touch · 触感

Widget 换位是「把卡片挪到桌上另一处」

抬起时阴影扩大、落下时回弹，落点明确；这正好是修掉现有布局挤压 bug 的动画语言（不动 grid 的 transform，只动阴影与透明度）

128
texture · 质感

hover 一个数字时能感到「颗粒」

给 KPI 数字一条极淡的 grainGradient 底，只在 hover 时显影

sound · 声音

声音的视觉等价

状态变化用「一声」= 一次 120ms 的短闪（不是持续发光），持续发光只留给正在进行的事

temperature · 温度

用色温表达结果而不是只用红绿

入库成功给一次暖色（warning 色相偏橙的合法用法），失败给一次冷掉

weight · 重量

span=2 的宽卡比 span=1 的重

入场晚 60ms、退出早 60ms，让面板有排字的节奏而不是齐刷刷一起

humidity · 湿度

光晕在暗档更「湿润」，亮档更「干」

光晕（pulse）在暗档更「湿润」（blur 更大、透明度更低），亮档更「干」（收紧）——同一语义两档不同参数

taste · 味道

整站是「纸墨 + 一点柑橘强调色」

头像组合器里的色族命名走味觉（ink / citrus / moss / slate / plum），比 hex 好记

左边是故意做烂的样子（噪、要人反复确认、霸屏），右边是翻正之后本轮该写的规则。每一条都在说同一件事：别跟用户要确认，给他撤销。

06

我们可以怎样How Might We · 人机交互维收敛成机会句再出招

八句机会句，每句下面接一个能直接写成组件的答案。模式感来自背景而不是弹层，因果要在落定前被看见。

8 idea · 8 机会句
HMW 01让人一眼看出面板处于「可编辑」？
顶栏那把「自定义面板」按下后，整块 grid 进入虚线网格底（CSS repeating-linear-gradient 的编辑栅格线），离开即消失——模式感来自背景而不是弹层
HMW 02让「移动」在语义上不必左右？
给每卡一个序号芯片（1/2/3…），点芯片输入目标位次；比连续点左移快，且键盘可用
HMW 03让 resize 的意图被看见？
点击「加宽」时先做一次 300ms 的预览描边（邻居让位的虚线轮廓），再落定；让因果可见
HMW 04让侧栏自定义零学习成本？
复用概览的心智：一个「自定义」开关，条目右侧浮出「隐藏」与「上/下」，与 Widget 同一套图标与文案
HMW 05让人知道刚发生的事而不是去猜？
所有状态跃迁（processing→ready）在卡片左上做一次 120ms 的边缘闪光 + 一条「刚刚：X 就绪」的瞬时行，2s 后自清
HMW 06让入库这一步「有下一步」？
成功后给三个动作：立刻问它（跳 /ask 带上下文）、看它分块（跳资源详情）、继续入库（焦点回输入框）——把一次写入变成一个循环的入口
HMW 07减少表单的认知负担？
标题字段默认折叠成「+ 指定标题」，因为 90% 情况自动取标题是对的；把可选意图从视野里拿掉
HMW 08让视效不吵？
一个全局「动效强度」三档推子（静默/克制/尽情），写进 localStorage，默认克制；减动效系统偏好强制落到静默档

SCAMPER 的 Eliminate（去掉 exit 动画里的 scale）与 Sensory 的纸触感（按下是下沉不是缩放）其实是同一条——本轮 Widget 的布局挤压 bug 的根因，很可能就是 scale 与 layout 投影在同一元素上打架。

四象限MoSCoW · 本轮是要落建的，不是只看可能性

Must 那格在呼吸，因为它是本轮唯一被允许发光的一块面；Won't 那格划掉，是为了守住 P1 的半径。

4 decision

Must
