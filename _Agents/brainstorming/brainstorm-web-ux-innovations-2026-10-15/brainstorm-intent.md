# Brainstorm Intent — 本轮 app/web UX 优化（2026-10-15）

> 来源：`_Agents/brainstorming/brainstorm-web-ux-innovations-2026-10-15/.memlog.md`（90 条，5 轮发散 + 亲和簇 + MoSCoW）。
> 这份只留选中的方向，给本轮实现直接消费，不带报告的赘述。

## 贯穿判断（三簇其实是一件事）

- **「纸不是玻璃」**：本项目的美术语言是纸。纸的反馈是*压下去*（阴影变浅 + 1px 下沉），不是 scale 收缩。
  这条同时给出了 Widget 布局挤压 bug 的诊断方向：**同一元素上 `layout` 投影 + `scale` 动画在打架**（memlog 里 SCAMPER-Eliminate 与 Sensory-触感 两条的交点）。
- **「动要携带信息」**：呼吸的节奏 = 数据更新的节奏；一次性的 120ms 边缘短闪 = 「刚刚变了」；**持续发光只留给正在进行的事**。一条动则全场静。
- **「视效强度是一档审美，不是无障碍降级」**：全局三档推子（静默 / 克制 / 尽情）写本机；`prefers-reduced-motion` 强制落到静默档。这让「加更多视效」和「不吵」不再互相否决。
- **「介绍不是删掉，是挂到触发点上」**（展签模式）：同时满足「不需要介绍」和「warning 必须看得懂」。

## Must（本轮必做）

| # | 交付 | 要点 |
|---|---|---|
| M1 | 修 Widget 移动/放大挤掉邻居 | 拔除同元素的 `scale` 与 `layout` 并存；换位用「抬起—落下」（阴影+opacity），不动 grid 的 transform；额外给一个**重排自救**出口 |
| M2 | 头像组合器 | 三维正交：Effect × ColorFamily × Speed；预览区**永远只 1 个 WebGL context**，侧栏那颗用 `toDataURL` 烘焙快照（不占预算）；配置 + 快照存本机；可导出 JSON |
| M3 | 侧栏自定义 | 显隐 / 排序 / 恢复默认；**灰掉而不删**（电梯面板隐喻）；复用概览那套「自定义」动词、图标与存档心智，不新造第二套 |
| M4 | 入库面板重做 | 删掉介绍卡与冗余说明；标题字段折叠成「+ 指定标题」；把管线画成一条**步骤带**（抓取→解析→切块→嵌入→写库）；成功后给三个动作（立刻问它 / 看它分块 / 继续入库）；布局更紧凑 |
| M5 | 视效三档推子 | `静默 / 克制 / 尽情`，默认克制；一份 localStorage 真相，`ShaderBackdrop` 与 Motion 的入口都读它 |

## Should

- 编辑态给整块 grid 铺**虚线栅格线**（CSS `repeating-linear-gradient`），让「我在编辑」从背景被感知，而不是靠弹层。
- 点击「加宽」时先做一次 300ms 的**让位预览描边**，再落定 —— 让因果可见。
- `move` / `resize` 给**一次撤销**（不可撤销的才两步确认：恢复默认保留两步）。
- 状态跃迁（processing→ready）在卡片左上做一次 120ms 边缘短闪 + 一条 2s 自清的瞬时行。

## Could（有余量才做）

- 侧栏每条导航带一个状态点（资源=数量 / 探针=红绿 / 入库=忙），导航变成仪表板。
- 「最近入库」翻牌式逐行更新（只翻变化那一行）。
- KPI 数字换值时一次 halftone 溶解再聚拢。

## Won't（本轮明确不做，别顺手加）

拖拽 DnD 依赖 · 命令面板（mod+K 二态）· 全屏 shader 海洋 / 透镜光标 · 任何把配置存到后端的方案（P1 无账号红线，AGENTS §五）。

## 验收口径（可核对）

- M1：连续 move 与 resize 各 10 次后，DOM 里**没有任何残留 inline transform**，邻居不重叠、不消失；点「重排」立即恢复正确栅格。
- M2：打开组合器时 `getContext('webgl2')` 调用数 = 1；关组合器后回到 0；侧栏那颗头像在无 WebGL 也画得出来（快照）。
- M3：隐藏一条导航后刷新仍在；恢复默认后与 `NAV` 常量逐项一致；Find 过滤与自定义共存时不丢状态。
- M4：`/ingest` 页面文字量比改造前少；提交中步骤带按真实阶段推进；成功条里三个动作都可点且真跳转。
- M5：切到静默档后全站零 `canvas`、零 transition（纸纹与 hairline 保留）；`prefers-reduced-motion: reduce` 时档位被强制为静默。
